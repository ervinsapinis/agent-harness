# Changelog

## 0.1.0
- The always-on decision protocol, as the `deliberate` output style.
- The `init` skill, which sets up a project layer, including for projects with no code yet.
- The `decide` skill, which records decisions in the ledger.
- The on-demand `reviewer` agent.
- A marketplace manifest. The README covers install and update.
- A start prompt for an existing project.
- `docs/status.md` for status and roadmap, and `.claude/CLAUDE.md` for sessions that work on the harness.
